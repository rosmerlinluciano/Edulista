# EduLista

## 1. Descripción del proyecto

EduLista es un sistema diseñado para facilitar a los docentes el registro y control de la asistencia de los estudiantes de manera rápida, sencilla y organizada.

## 2. Objetivo del sistema

El objetivo de EduLista es ayudar a los profesores a registrar la asistencia de sus estudiantes y mantener la información organizada.

## 3. Problema que resuelve

El registro manual de la asistencia puede provocar errores, pérdida de información y dificultades para consultar los datos. EduLista busca reducir estos problemas mediante una mejor organización de los registros.

## 4. Funcionalidades principales

- Registro de usuarios.
- Inicio de sesión.
- Registro de estudiantes.
- Registro de asistencia.
- Consulta de la asistencia registrada.
- Organización de la información de los estudiantes.

## 5. Arquitectura del sistema

El proyecto propone una arquitectura por capas, organizada de la siguiente manera:

- **Interfaz de usuario:** permite al docente utilizar el sistema.
- **Autenticación:** permite gestionar el acceso de los usuarios.
- **Lógica de negocio:** procesa las operaciones y valida la información.
- **Base de datos:** permite almacenar y organizar los datos.

## 6. Organización del frontend y backend

**Frontend:** es la parte visual con la que interactúa el usuario.

**Backend:** es la parte interna encargada de procesar las solicitudes y gestionar las operaciones del sistema.

**Base de datos:** almacena la información de los usuarios, estudiantes y asistencias.

La comunicación entre el frontend y el backend se plantea mediante solicitudes que permiten procesar y consultar la información.
